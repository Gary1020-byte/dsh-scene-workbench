## 二、過程中踩到、並已修正的坑

這五個坑每一個都會讓分頁**靜默消失**，而且不報錯。

### ① `exports` 沒開放 `./package.json` → client 半邊被整個跳過

引擎用 ESM 解析列的套件名，找不到 manifest 就 `return`（沒有例外、沒有 log）。

```
ERR_PACKAGE_PATH_NOT_EXPORTED
```

⇒ 官方套件的 `exports` 都有一條 `"./package.json": "./package.json"`。
Node 的 `exports` 會擋掉沒宣告的子路徑，**少這一條就等於沒有 manifest**。

### ② 服務要宣告在 module 的 `exports.inject`

```js
return { inject: ['slots','locale','sidebarRightTabs','sidebarRight','remote','remote.workspaceFiles'], apply }
```

宣告過的服務會**直接掛在 ctx 上**（`ctx.slots` / `ctx.locale` …）。

`ctx.inject([...], cb)` 是「等某服務就緒再給你」的**延遲機制**，
不是取得服務的方法——它 callback 的 scope 只帶新注入的那一個。

### ③ locale 字典是「扁平 + 點號 key」

```js
const zh = { 'guide.title': '場景' }   // ✅
const zh = { guide: { title: '場景' } } // ❌ 渲染成字面 key「guide.title」
```

引擎按**整串 key** 查，不做巢狀走訪。

### ④ `workspaceFiles.read` 的 `range.offset` 是 1-based

傳 `{ offset: 0 }` 會整個讀取失敗（§₀ 交接摘要因此永遠是空的）。

⇒ `{ offset: 1, limit: 160 }`。

### ⑤ 註冊 tab type 不會自動開分頁

`sidebarRightTabs.register(def)` 只是把「一種分頁」登記進去。
使用者的分頁列不會憑空多一頁——**還需要一個開啟入口**。

本 repo 用兩個入口：
- **guide 條目**：Start 頁的「工具」清單會列出「場景」，點它就開分頁（`commandId` 指向 shortcut）
- **shortcut**：`Ctrl/Cmd + Alt + J`
